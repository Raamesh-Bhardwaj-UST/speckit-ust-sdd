# Dark Mode Standardization Seed (extension)

Packages the `001-dark-mode-standardization` feature from observex-ui as a reusable starting point.

- `assets/reference-spec.md`: framework-agnostic spec (copied into the new feature, placeholders filled from the repo)
- `assets/reference-plan-guidance.md`: decisions and lessons to apply when writing a real plan
- `assets/reference-tasks.md`: phase/user-story shape for `tasks.md`
- `assets/worked-example-angular/`: the original observex-ui spec/plan/research/contract/tasks and the
  Angular `ThemeService`, toggle component, and token CSS

Usage: `/speckit-dark-mode-standardization-seed` in Copilot Chat.
