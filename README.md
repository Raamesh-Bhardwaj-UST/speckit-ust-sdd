# speckit-ust-sdd

A Spec Kit (v1.0.12+) **bundle** that packages the spec-driven development setup built in
`observex-ui` so any repo can install it with one command.

| Kind | ID | Version | Adds |
|---|---|---|---|
| bundle | `ust-sdd` | 1.0.0 | Installs the three components below together |
| preset | `ust-brownfield-sdd` | 1.0.0 | Stack-agnostic brownfield constitution template + grounded `/speckit-constitution` |
| extension | `ust-sdd-agents` | 1.0.0 | `/speckit-ust-sdd-agents-setup` → Architecture Discovery, Spec Generation & Enrichment, Developer agents |
| extension | `dark-mode-standardization` | 1.0.0 | `/speckit-dark-mode-standardization-seed` → spec/plan guidance/tasks from feature 001 |

Integration: GitHub Copilot, PowerShell scripts.

## Layout

```text
bundles/ust-sdd/bundle.yml      # the bundle manifest (+ README.md)
extensions/<id>/extension.yml   # extension sources
presets/<id>/preset.yml         # preset source
catalogs/{bundles,extensions,presets}.json   # generated by scripts/release.py
scripts/release.py              # zips components, computes sha256, regenerates catalogs
```

Important: `specify bundle install` doesn't copy extensions/presets from this folder. It reads
`bundle.yml` and fetches each component **by ID from the registered extension/preset catalogs**.
So publishing means: component zips on a GitHub release, plus the three catalog files on an HTTPS URL.

## Publish (maintainer)

1. Create the repo `Raamesh-Bhardwaj-UST/speckit-ust-sdd` (private or internal is fine) and push this folder as its root.
2. Generate zips and catalogs for the tag:
   ```powershell
   uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@v1.0.12
   python scripts/release.py --tag v1.0.0     # use the python from the specify-cli tool env if pyyaml is missing
   ```
3. Commit the updated `catalogs/*.json`, tag and push:
   ```powershell
   git add catalogs; git commit -m "Release v1.0.0"; git tag v1.0.0; git push origin main --tags
   ```
4. Create the GitHub release and upload the zips:
   ```powershell
   gh release create v1.0.0 dist/*.zip --title "ust-sdd v1.0.0" --notes "Initial release"
   ```
5. Check it from any Spec Kit project (see *Install*): `specify bundle info ust-sdd`.

**Releasing a change:** bump the version in the changed `extension.yml`/`preset.yml`, update the pin
in `bundles/ust-sdd/bundle.yml`, bump `bundle.version`, then repeat steps 2–4 with a new tag.
Consumers run `specify bundle update ust-sdd`.

## Install (consumer repo)

Prerequisites: `uv`, `git`, PowerShell 7 (`pwsh`), VS Code + GitHub Copilot. For a private repo, set a token
that can read it: `$env:GH_TOKEN = "<PAT with repo read>"` (or `GITHUB_TOKEN`).

```powershell
# 0. Spec Kit CLI (once per machine)
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@v1.0.12

# 1. In the target repo: initialise Spec Kit for Copilot + PowerShell (skip if .specify/ already exists)
cd <target-repo>
specify init --here --integration copilot --script ps --force   # --force: merge into a non-empty repo

# 2. Register the UST catalogs (project-scoped, written under .specify/)
$raw = "https://raw.githubusercontent.com/Raamesh-Bhardwaj-UST/speckit-ust-sdd/main/catalogs"
specify extension catalog add "$raw/extensions.json" --name ust --install-allowed
specify preset    catalog add "$raw/presets.json"    --name ust --install-allowed
specify bundle    catalog add "$raw/bundles.json"    --id ust

# 3. Install the bundle
specify bundle info ust-sdd
specify bundle install ust-sdd

# 4. Commit what Spec Kit generated
git add .specify .github; git commit -m "Add ust-sdd Spec Kit bundle"
```

Then in Copilot Chat:

1. `/speckit-ust-sdd-agents-setup`: copies the 3 agents into `.github/agents/` and seeds
   `.github/instructions/architecture.instructions.md` (never overwrites existing files without `force`).
2. Agent **Architecture Discovery** → `full`.
3. `/speckit-constitution`: fills the UST brownfield constitution from the repo.
4. Feature work: **Spec Generation & Enrichment** or `/speckit-specify` → `/speckit-plan` → `/speckit-tasks` →
   **Developer** or `/speckit-implement`. For dark mode: `/speckit-dark-mode-standardization-seed`.

Manage: `specify bundle list` · `specify bundle update ust-sdd` · `specify bundle remove ust-sdd`
(removes only what the bundle added).

### Without hosting (local testing only)

```powershell
specify extension add --dev <path>\extensions\ust-sdd-agents
specify extension add --dev <path>\extensions\dark-mode-standardization
specify preset add --dev <path>\presets\ust-brownfield-sdd --priority 5
```

This path skips the bundle record: `specify bundle install <path>\bundles\ust-sdd\bundle.yml` sees the components as
independently installed and won't attribute or remove them.
